# 柚叶的初始记忆（memory seed）

每次测试都从这份记忆开始：卡里的长期内容只留身份和一句关系轮廓，柚叶和玩家之间的官方往事放在这里，作为 memkit 的记忆文件。这样它们和测试中新写入的记忆走同一条召回路径（BGE → Jev 判别），每次想起都能在 trace 里追溯到一次召回，而不是由卡直接喂给模型（CLAUDE.md §2）。

- 格式与 memkit 写入的文件完全一致：`<侧>/<principle|event>/<名字>.md`，frontmatter 每行 `key: <json>`，正文是 `- ` 开头的条目。文件名 = `slug(topic)`。多出来的 `importance` 一行 memkit 读的时候会忽略，只由 `memstore_reset.sh` 用来写 `.meta.sqlite`（见下）。
- 侧的划分：`user/` = 关于玩家的事、玩家做过和说过的事；`assistant/` = 柚叶自己的经历、承诺、心情和习惯。条目里柚叶自称「我」，玩家写作「哲」。
- 校验：`node --test tests/seed.test.ts`（仓库根目录）（用 memkit 的 `MemoryStore` 读入、检查字段、主题里没有时间词、条目里没有相对时间词、BM25 能找到已知条目）。
- 注入：在 gateway 所在机器上停掉 gateway 后跑 `scripts/ops/memstore_reset.sh <run-name>`（默认读本目录），步骤见 `docs/DEPLOY.md` §5。

## 玩家是铃的部署

种子按玩家 = 哲写成（哲的妹妹是铃）。部署给玩家「铃」时要换掉兄妹：把条目和摘要里的「哲」换成「铃」、「妹妹铃」换成「哥哥哲」、「哲和铃」换成「铃和哲」，文件名 / topic 里带「哲」的四个文件（`哲和录像店`、`哲在卫非地风波里`、`哲在绮梦度假村`、`哲放鸽子的旧账`）和 `怎么称呼哲`、`给哲发消息的习惯`、`和哲出海钓鱼` 同时改名。还要检查语料里按性别分支的那两处：怪啖屋邀请时铃版是铃替哥哥说「哥哥的软肋又被拿捏了」，而不是「请容我拒绝」（`20_story_main.md` L1672）。

和负责人建议的「卫非地 2026-06、度假村 2026-08」差了一年：放进篝火晚会之后有两个暑假，第二个必须在今天（2026-11）之前，所以整体前移到 2025。若决定不要篝火晚会，删掉 `assistant/event/度假村篝火晚会.md`、把其余日期加一年即可。

**遗忘曲线**：memkit 的召回排序乘 `0.5^(距上次更新天数 / 30)`，「上次更新」取 `.meta.sqlite`，没有这一行时从 frontmatter 的 `updated` 回填。按上面的日期回填，开局时卫非地那批文件的遗忘系数约 1e-5、度假村约 5e-5、篝火晚会约 0.25，等于开局就被埋掉——那样卡里删掉的内容就再也想不起来了。所以 `memstore_reset.sh` 注入后为每个文件写一行 meta：`created/updated = 注入时刻`、`importance = 本文件 frontmatter 的 importance`。往事的「旧」体现在 `times` 和条目措辞里，遗忘从测试开始那一刻算起。

## 刻意没有放进来的

`personas/yuzuha/story/` 的节拍要「第一次讲给玩家听」的东西一律不放：平心堂和苦药、海上抱着浮板漂流和泅珑围的海、澄辉坪的缆车和转学的同学、在店里一起看狸猫电影、小时候的事（包括实验室、「小蜡烛」、发卡的来历、射击摊和庆典的童年回忆、人鱼之梦）、《不可触碰》、冰淇淋、阿釜挠破手指、「怪房客」、难缠的客人、爱丽丝闷闷不乐。卫非地一节只写她「拿自己跟菲洛克斯做交易」，不写交易的筹码和她与那座实验室的关系；逃生时也只写「顺着地下河」，不写拆木板当浮板。
