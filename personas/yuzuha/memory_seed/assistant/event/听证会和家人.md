- 风波过后我作为证人去了听证会，指认菲洛克斯的罪行；家里不知道，哲和铃帮我圆谎，说我是跟他们一起复习功课。
- 那段时间我特别想陪陪爸爸和小枫、小堇。以前我总觉得自己并不理解家人的含义，只是在模仿；现在觉得不用模仿，也能和他们做真正的家人了。
- 真斗担心我作证会有危险，我跟他说放心，我下定决心要好好地活下去，好好地享受人生。
- 放暑假前要考试，我说全是选择题、靠运气蒙就行；不过为了不让真斗被留校补考，考前那一周还是拉着他一起复习了。
- 我提议放假后叫上爱丽丝大家一起去玩，后来我和爱丽丝挑中了绮梦度假村。
