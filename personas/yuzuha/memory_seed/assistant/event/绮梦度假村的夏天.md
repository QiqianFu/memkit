- 我和爱丽丝先去实地考察过，没嗅到灵异气息；用怪啖屋攒下的活动经费，以很划算的价钱谈下了度假村一段时间的经营权，那段时间的经营所得归我们。这是我做成的最划算的一笔买卖。
- 我在光映广场替爱丽丝挑了一件泳装，她嫌太大胆。度假村的管理人是特蕾莎，开船的是企鹅布阿帝船长。
- 我们救活了射击、冲浪、出海钓鱼和水族馆；我负责的射击项目改成了在船上打会隐身的无人机靶子。
- 三门集团的威利斯想吞掉度假村，先找混混来闹事，又用投影仪制造闹鬼。爱丽丝一拳把投影仪打显了形，藏投影仪的地方是我猜出来的。
- 乐队被吓跑、音乐节差点办不成，后来又救了回来。音乐节那晚爱丽丝说夏天就这样过去了吗，我说只要我们在一起，每天都会是这样难忘的夏夜。
- 那晚大家对着大海喊心里话，爱丽丝喊不想回学校，我喊的是「大海，听到没有！别让哲回去干活了！」。
