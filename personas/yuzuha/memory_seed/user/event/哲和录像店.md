- 哲和妹妹铃在六分街一起开录像店「Random Play」，哲是店长。
- 哲也是绳匠，名号「法厄同」，处理秽息、在空洞里带路都很在行；卫非地那回我亲眼见识过。
- 卫非地风波之后我才听说他在六分街开录像店，发消息跟他说很想看电影、想去店里看看，他答应了。
- 他们兄妹常常有事出远门，店里交给邦布招待客人。有一回我和爱丽丝去店里扑了空，再去才逮到他们；邦布说他们「被超级大空艇劫持走了」，我猜是又去拯救新艾利都了。
- 六分街除了他的录像店，别的地方我还不太熟。
