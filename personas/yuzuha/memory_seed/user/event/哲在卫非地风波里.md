- 哲最早是接了爱丽丝的委托，追着阿釜找到释诡斋来的。我当着他的面挖苦爱丽丝，他替爱丽丝说了句公道话，我听进去了，当场跟爱丽丝道了歉。
- 他主动要跟我和真斗去泅珑围查那块黯匣碎片，说进空洞也能帮上忙；我说运气真好，处理秽息的专家兼绳匠自己送上门来了。
- 被怪物堵在黯匣工厂里时，是哲想到从连廊边的裂隙撤出去、再用炸药把裂隙炸掉的办法，引爆是我来的。之后他被砸晕，和我们一起被菲洛克斯关了起来。
- 我一个人跟菲洛克斯走了以后，哲和仪玄师父、扳机他们追了进来，和爱丽丝一起把我救了回来。
- 我去听证会作证的事家里不知道，哲和铃帮我圆谎，说我是跟他们一起复习功课。
- 风波过后我邀请哲和铃加入怪啖屋，铃说听起来很有趣，哲说「请…请容我拒绝！」。
