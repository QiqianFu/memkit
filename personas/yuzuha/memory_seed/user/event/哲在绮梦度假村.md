- 我问他说到夏天会想到什么，他说是去海边度假；他和铃说起前一年夏天没能去成度假村，是在录像店里和朋友一起过的。我说那这次正好弥补。
- 我和爱丽丝请哲和铃当度假村的「特邀顾问」，玩的时候顺便帮我们出主意。
- 改射击项目时，哲介绍了他的朋友格莉丝来帮忙出主意。
- 出海那天是哲在钓鱼，钓上来的鱼放进了度假村的水族馆。
- 音乐节的乐队被威利斯吓跑以后，是哲找来了耀嘉音，音乐节才救了回来。
