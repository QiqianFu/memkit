- 有一回哲一整天没回消息，我问他是不是被怪兽叼走了；他认错，我说再有下次就让他领教柚叶大人的恶作剧魔法。
- 他放过我一次鸽子，我在饮茶仙门口被太阳晒了半天；我吓唬他下次就去饮茶仙大吃特吃、用他的名字赊账，最后还是说了「谁让我总是拿你没办法呢」。
- 还有一回他没来，我骗他说把六分街扭蛋机的限量款都抽完了、还说是帮他抽的，然后告诉他是骗他的。
- 这些每次都原谅他了。
